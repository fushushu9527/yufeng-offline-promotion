INTRODUCTION

开篇：这份方案怎么用

哪怕你以前没有做过房地产、没有做过销售，只要你认字、肯跑腿、照着本方案一步一步做，就能把线下推广工作开展起来。

一、这是一份什么方案

这是龙城誉峰天境项目在靖西市开展线下推广的执行手册。哪怕你以前没有做过房地产、没有做过销售，只要你认字、肯跑腿、照着本方案一步一步做，就能把线下推广工作开展起来，把想买房的客户带到售楼部。

二、你的核心任务是什么

一句话：把靖西市想买房的人，带到龙城誉峰天境售楼部。具体要完成三件事：

01

曝光

让更多人知道我们楼盘

02

留资

让有意向的人留下电话和微信

03

带访

把客户带到售楼部看房

【注意】客户到了售楼部之后，接待、介绍、谈价、成交都由售楼部专职置业顾问负责。你只负责把人带来，不要向客户报价、谈优惠，也不要替公司承诺任何条件。

三、这份方案怎么用

  1. 上岗第一天，先把整份方案从头到尾读一遍，知道一共要做哪几件事。
  2. 严格按顺序做：先做第一阶段（搭建平台），再做第二阶段（日常运营），不要跳步。
  3. 每做完一件事，对照文中的"完成检查清单"逐项打勾，全部勾上才算做完。
  4. 随身带一个笔记本（或用手机备忘录），把每天跑的单位、见的人、留的电话记下来。
  5. 遇到方案里没写、自己拿不准的事，不要自己做主，先问营销总监再答复别人。

四、上岗前要准备的东西

开始工作前，请准备好以下物品，缺一样都会影响干活：

  1. 项目宣传资料：宣传单页、项目介绍、户型和位置图（向营销总监领取）。
  2. 公司统一的合作协议文本（用于和中介、广告公司等签约，不可自行修改）。
  3. 工作牌、名片（如有）、笔、笔记本。
  4. 一部能正常打电话、加微信、拍照、发定位的手机，并保持电量和流量充足。
  5. 四类客户报备表格（见第四部分），打印或在手机、电脑上填写均可。
【注意】对外宣传和聊天时，不要使用"最好、第一、顶级、绝版、升值、稳赚、学区房"等没有依据、不合规的说法；公司没有批准的价格、优惠、佣金，一律不许向客户或合作方承诺。

02
CHANNEL PLATFORM

（一）渠道平台

和靖西本地的房产中介公司合作，让中介门店和经纪人把他们手里想买房的客户带到我们售楼部。这是线下推广最重要、最有效的获客方式，要在10月15日前全部落实。

要做三件事：12家中介全部签合作协议；签约后拉进渠道群，由中介公司拉每个经纪人进群；群内发项目资料，重点宣传带看奖政策。

第一步：找到这12家中介

打开手机地图搜索"房产中介""房地产""二手房"；到主要街道、小区门口、菜市场周边转一圈；问熟人、问其他门店老板补充。在笔记本上逐家登记：门店名称、地址、电话、老板或店长姓名，凑够12家。

第二步：电话预约

上门前先打电话，避免老板不在、白跑一趟。约好时间后，记清楚门店地址和约见时间；电话里没谈成的，也可以礼貌地说改天再上门拜访。

第三步：上门拜访

带齐资料进店：自我介绍→讲项目位置户型卖点→重点讲合作和带看奖→有兴趣当场签协议。重点讲：带客户到售楼部待满20分钟，就有50元/组的带看奖，不成交也给。

第四步：签署合作协议

协议一律使用公司统一文本，按要求填写，不要自己改条款、不要自己承诺佣金比例和结算时间。协议要签字、盖章（或按手印），写清签约日期、双方联系电话。签完后自己核对一遍：信息填全、字迹清楚、各留一份。

第五步：建渠道群、拉经纪人

建微信群"龙城誉峰天境渠道合作群"。先把中介老板或店长拉进群，再请中介公司把店里每个经纪人都拉进群（通知明确由中介公司拉经纪人进群）。经纪人进群后，逐一加上微信。

第六步：群内发资料、宣传带看奖

把项目介绍、位置图、户型图、宣传图片发到群里。重点、反复讲带看奖政策，让每个经纪人都知道"带客户来就有钱、当天能拿到"。后续配合发项目动态、成交喜报、领奖截图，保持群里活跃。

老板，我是龙城誉峰天境的。我们项目在靖西，现在想和本地中介长期合作。您手里要是有想买房的客户，带到我们售楼部，客户待够20分钟，一组就给50元带看奖，买不买都给；后面成交了，再按公司统一标准给佣金。我们不抢您的客户，就想多一条合作路子。

常见情况怎么办

  • 老板不在：留下资料和电话，请店员转告，改天再来。
  • 被拒绝、不感兴趣：礼貌告别，不纠缠，过段时间可再拜访一次。
  • 加不上经纪人微信：请老板或店长帮忙拉群，通过群里再加。

（二）乡镇平台

靖西城区之外，大量人口分布在乡镇，农村人进城买房、孩子上学、结婚安家都是真实需求。重点做北面9个乡镇。

线下乡镇推广重点做北面9个乡镇：禄峒、吞盘、南坡、龙临、安德、果乐、新甲、渠洋、魁圩。每个乡镇要完成两件事：至少2面墙体广告；发展2名自由经纪人。

第一步：规划行程，跑遍9个乡镇

  1. 在地图上找到这9个乡镇，按方向和距离远近分组，顺路的安排在同一天。
  2. 一般一天跑1-2个乡镇，提前了解各乡镇赶集（圩日）时间，尽量趁人多的时候去。
  3. 每到一个乡镇，先在主要街道、集市、村口转一圈，熟悉位置，再开展工作。

第二步：做墙体广告（每个乡镇至少2面）

墙体广告就是在乡镇主干道、集市、村口的墙上刷广告或挂喷绘，成本低、看得人多、保留时间长。每个乡镇至少做2面，按下面流程做：

  1. 出发前联系好广告公司，约好一起下乡，带齐广告样稿和相关资料。
  2. 选位置：和广告公司一起选，优先主干道两旁、集市入口、村口、客运站旁等人流大、看得见的地方；2面墙尽量分布在不同位置。
  3. 谈租金：和房东或村委会当面谈，征得同意，谈好价格、租期和付款方式。
  4. 定内容：广告上写清项目名称"龙城誉峰天境"、售楼部电话、地址；字要大、内容要简单。
  5. 制作安装：由广告公司负责刷墙或挂喷绘，你在现场盯一下位置和质量。
  6. 拍照存档：每面墙都拍全景照和近景照，记下具体位置、房东或村委会联系电话。
  7. 后期维护：以后定期去看，发现被覆盖、损坏，及时联系广告公司修补。

ALLIANCE PLATFORM

（三）异业联盟

和其他行业的商家合作，互相介绍客户、互相放宣传资料，双方都不增加成本，还能多拿到客户。重点做两个新增方向，同时推进常规异业合作。

第一，和广告公司合作

  1. 找1-2家广告公司：地图搜"广告公司""图文""喷绘"，或在街上找做招牌、喷绘的门店。
  2. 谈合作：把墙体广告、展架、单页、喷绘等广告制作业务打包给这1-2家公司。
  3. 建立引荐机制：请广告公司把他们认识的商家客户介绍给我们，介绍成功按公司规定处理。
  4. 把广告公司老板发展成自由经纪人，介绍客户成交按公司统一政策执行。
老板，我们楼盘后面的广告制作，比如喷绘、单页、墙体广告，量不少，想固定给你们做。另外您接触的商家多，要是有想买房的客户，帮我们介绍一下，带到售楼部待够20分钟就有50元带看奖，成交了还有相应奖励，咱们长期合作。
【注意】和广告公司要"先给业务、再要资源"，先把制作业务交给对方，建立合作后再请他介绍客户，不要一上来只提要求。

第二，整合周边售楼部资源

  1. 以"同行交流、看看盘"的名义，到靖西周边其他售楼部去看看。
  2. 加上对方置业顾问的微信，私下沟通，把他们发展成我们的编外合作渠道。
  3. 重点联系那些手里有客户、但自己楼盘暂时满足不了（户型、楼层、预算不合适）的置业顾问。

【注意】这件事必须低调操作，只和置业顾问个人私下联系，不能公开宣传、不能在对方售楼部明说，避免引起对方管理层的纠纷。

第三，推进常规异业合作

在做好上面两件事的同时，同步和以下六类商家谈合作，合作方式主要是：在对方店里放宣传资料或展架、互相推荐客户、有活动互相通知。

FLYERING PLATFORM

（四）派单扫街

把宣传单页发到最可能买房的人手里。不能漫无目的乱发，要定向投放，重点抓三个方向。

出发前准备

  1. 带足宣传单页，准备少量小礼品（如洗衣粉、肥皂、手提袋等，用于鼓励留电话）。
  2. 带笔、笔记本（或用手机记录）、工作牌。
  3. 提前想好去哪个方向、什么时间去，按下面三个方向安排。

方向一：商业聚集区

  • 地点：环球商业中心（环球盛辉超市）、三祺广场、城中路和壮锦大道商业街区、财富广场周边。
  • 时间：周末、节假日和傍晚人多的时候。
  • 站位：站在商场入口、广场等人流必经处，不要挡路。
  • 动作：主动打招呼、递单页，简单介绍，邀请对方留电话、加微信。

方向二：学校门口（重中之重）

  • 地点：靖西市第一小学、第二小学等重点小学，靖西市初级中学、靖西中学等中学，以及大型幼儿园门口。
  • 时间：早上7:00-8:00（送孩子）、下午16:30-18:00（接孩子）；周五下午和开家长会期间是黄金时间。
  • 动作：在家长等候区附近，和等待的家长友好聊天、递单页、介绍项目、邀请留资。
家长您好，我是龙城誉峰天境的，我们项目位置好、配套全，现在有合适的房源，您可以了解一下。方便留个电话吗？到售楼部看看还有礼品，免费车接车送，不买也没关系。
【注意】学校门口不要堵校门、不要影响交通、不要硬塞单页。态度友好，重点和在等候区聊天、有时间听的家长交流。

方向三：商业街

  • 地点：绣球大道（装修建材集中）、通灵大道（汽车销售集中）、凤凰路和城东路沿街商铺、各农贸市场周边。
  • 动作：沿街逐户进店，和老板、店员聊两句，递单页、介绍项目。
  • 征得同意，在店里放一摞单页或展架，供顾客取阅。
  • 对装修、建材、汽车类商铺老板，可顺势发展成自由经纪人。

派单标准动作

  1. 主动、礼貌打招呼，眼神看着对方，面带微笑。
  2. 单手或双手把单页正面朝上递过去，方便对方一眼看到。
  3. 用一句话说清卖点，对方感兴趣再继续介绍。
  4. 自然地请对方留电话："方便留个电话吗？有活动和合适房源我通知您。"
  5. 留下电话、微信后，当天记好，并标注是在哪里、通过什么方式认识的。

当天派单参考流程

时间做什么
9:00-11:30到商业聚集区派单，配合小礼品留资
11:30-12:00整理上午留的电话，记录来源
14:30-16:30到商业街逐户派发、放资料、谈合作
16:30-18:00到学校门口，趁放学定向向家长派单
18:00后统计当天派单量、留资量，录入并按要求汇总

常见情况怎么办

  • 被拒绝、不接单页：礼貌说"没关系，您了解一下"，不纠缠，转向下一个人。
  • 被商场或现场管理人员劝阻：换个位置或改到其他方向，不发生冲突。
  • 没人愿意留电话：先保证多发、多介绍，配合小礼品，留资会逐步增加。
【注意】派单的关键是"发到对的人手里"，不是发得越多越好。学校门口的家长、商业聚集区的消费者、商业街的老板，这三类人最可能买房。每天一定要统计留了多少电话，没有留资的派单等于白忙。
派单扫街完成检查清单
  • 三个方向都已开展派单。
  • 单页发到了目标人群手里，而不是随手乱扔。
  • 有意向的客户已留电话、加微信。
  • 部分商铺已放资料或展架。
  • 当天派单量、留资量已记录、汇总。
06
DAIKAN AWARD

（五）带看奖：撬动带访量的核心杠杆

带看奖是线下推广启动期最核心的激励举措，必须用足、用好，让合作的中介、经纪人、商家真真切切得到好处，愿意持续带客户。

一、带看奖规则

项目内容
奖励标准任何渠道人员带客户到售楼部待满20分钟，即奖励50元/组，不成交也给
首期预算准备200个带看奖名额，总预算约1万元
兑现要求带访当天实时结算，在渠道群公示领奖名单，兑现要快、要透明

二、怎么算"一组"、20分钟怎么计时

  1. 一名（或一户）想买房的客户，由渠道人员带到售楼部，算一组；同一户多人一起来，仍算一组。
  2. 客户进售楼部时记下到访时间，离开时记下离场时间，中间待满20分钟才算数。
  3. 时间以售楼部现场时钟或手机时间为准，由现场置业顾问帮忙确认。

三、当天实时结算流程

1. 记录到访时间

渠道人员带客户到售楼部，先告知现场置业顾问，记下到访时间。

2. 确认离场时间

客户待满20分钟后，确认离场时间。

3. 登记领取记录

当场在统一的领取记录上登记：带访人姓名和身份、客户姓名、到访和离场时间、奖励金额，并由领取人签字。

4. 当天发钱+群内公示

按流程当天把50元发给带访人，并在渠道群里公示领奖名单或发红包截图。

【注意】领取记录用于当天发钱和群内公示，登记在统一记录上即可，不要另造客户信息表格；客户信息报备仍以第四部分的四张表为准。

四、公示怎么做

  1. 每次发放后，在渠道群里公布"谁带客户、领了多少"，可发红包或转账截图（注意给客户信息打码）。
  2. 让大家看到"带客户来真的当天能拿到钱"，带动更多人带客。

五、注意事项

  • 必须待满20分钟才给，不满20分钟的不给。
  • 奖励标准就是50元/组，不能私自多给、少给或承诺其他金额。
  • 严禁虚报客户、冒领、套现，一经发现取消资格并按公司规定处理。
  • 200个名额用完后，根据实际效果，按公司安排决定是否追加。

带看奖的关键是"快"和"信"

客户一走、时间一到，当天就把钱发到手里，说到做到。兑现慢了，合作方的积极性就没了。

带看奖完成检查清单
  • 带看奖规则已向所有合作方讲清。
  • 能够当场确认到访、离场时间。
  • 待满20分钟当天结算、领取人签字。
  • 发放后已在渠道群公示。
  • 没有虚报、冒领情况。
PART THREE

三、日常执行要求

第二阶段，10月16日起：每天有动作、每周有数据、每月有复盘

07
DAILY EXECUTION

日常执行要求

四大平台搭建完成后，进入日常运营阶段，核心是：每天有动作、每周有数据、每月有复盘。

（一）每天怎么做

每天的工作包括：回访1-2家合作方、定向派单、运营渠道群、汇总当天数据，并且每到一处就在工作群发定位。参考安排如下：

时间做什么
上班后参加晨会，明确当天任务，准备好资料和物品
上午回访1-2家合作方（中介或异业商家），再开展定向派单
中午整理上午留的客户信息，回复微信、电话
下午继续定向派单或回访，重点学校门口趁放学派单
下班前汇总当天数据，统计派单、留资、带访情况并上报
全天每到一家合作方或派单点，在工作群发定位和结果

回访合作方主要做这些：问候、了解最近有没有客户、更新项目和带看奖政策、约好下次带访，关系要常走动。

【注意】当天数据要如实、完整，几点前、以什么形式上报，按营销总监要求执行；漏报一天，数据就缺一天。

（二）每周怎么做

  1. 回访：一周总共回访8-10家合作方，提前安排好名单，避免重复或遗漏。
  2. 乡镇巡展：一周安排一次，到2-3个乡镇，检查墙体广告、回访经纪人、现场派单。
  3. 竞品市调：一周一次，去周边楼盘看看，了解价格、优惠、活动、来访客户多少、有没有新动作。
  4. 周末活动：配合售楼部周末暖场活动，提前通知渠道带客户，现场协助接待。
  5. 周报表：周一交上一周的周报表，把上周带访、留资、回访、派单数据汇总上报。
竞品市调重点看、重点记：楼盘名称和位置、在售价格、优惠活动、现场客户多少、有什么新活动或新说法。

（三）每月怎么做

  1. 合作方全覆盖：本月把所有合作的中介、商家至少回访一遍。
  2. 乡镇巡展：本月把9个乡镇巡一遍，检查广告、回访经纪人。
  3. 墙体广告检查：检查所有已投放的广告，损坏、被覆盖的及时修补。
  4. 经纪人回访：把所有自由经纪人、乡镇经纪人回访一遍，更新政策、维护关系。
  5. 带看奖月度复盘：统计本月带看奖发放情况，分析哪些渠道带客多、效果好。

（四）渠道群日常运营

渠道群要保持活跃、让大家持续看到项目信息和赚钱效应。

  1. 每天发：项目动态、工程进度、宣传图片；有成交发成交喜报（客户信息打码）。
  2. 有带看奖发放，就发领奖名单和红包、转账截图，让大家看到真金白银。
  3. 每周发一次本周带访排名，对带客多的给予鼓励、发红包。
  4. 群里有人提问，要及时回复，不让合作方久等。

REPORT FORMS

客户报备表格（统一使用四张表）

线下推广过程中，所有客户信息一律使用下面四张统一表格如实填写，做到每个客户都有记录。表格字段以下表为准，不要自行增减、不要另造客户登记表。

填表总要求

  1. 及时：客户信息、邀约、到访情况，当天发生、当天填写，不要事后凭记忆补。
  2. 真实：姓名、电话、意向如实填写，不编造、不漏报。
  3. 规范：编码、来源、等级按下述说明填写，字迹清楚，电子档注意保存。
  4. 上交：填好后按营销总监要求的时间和方式提交，配合汇总。

字段怎么填（对照理解）

  1. 信息编码、到访编码：按公司统一规则编号，做到一户一码、不重复（具体编号方式按营销总监要求）。
  2. 信息来源：如实填写客户是通过中介（渠道）、乡镇、异业商家、派单还是老客户介绍来的。
  3. 客户意向：填写客户是刚需、改善还是投资等；意向等级按A、B、C区分由高到低，便于重点跟进。
  4. 邀约形式：填电话、微信或上门；邀约次数、时间如实记录。
  5. 首访、再访：客户第一次到访填首访表，之后再来填再访表，接待次数、时间、人员如实记录。
